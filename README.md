## The five reasons a working code gets rejected

A code can be perfectly real and still refuse to apply to your order.

**You're not a new customer.** This is the big one. The overwhelming majority of high-value Uber Eats codes are first-order promos. A McDonald's US promotion gives new customers $5 off a first order of $20 or more with the code `mcds2026`, valid through 31 December 2026. It's a real code with real terms, and it will do nothing for an account that has ordered before.

**You're in the wrong country.** Codes are region-locked at the account level. Student Beans lists $10 off a first order over $30 in Australia, capped at 1,000 uses. ISIC lists €10 off each of the first two orders in Germany, minimum €20, capped at 1,000 users, valid through 31 December 2026. Same platform, two different deals, and neither works in the other country.

**You already used it.** Uber's own promo codes are typically single-use per account. Uber Japan published a code (`UETA4S`) for 75% off up to ¥2,000, explicitly limited to first-time Uber Eats users, one use per person, and valid only between 1 May and 30 June 2026.

**The usage cap ran out.** "Limited to 1,000 users" is a common clause. When those thousand people order, the code dies quietly — and the coupon site listing it doesn't get a notification.

**Your cart doesn't meet the minimum.** Minimum spend thresholds almost always exclude taxes, fees and delivery, so a $20 minimum can mean a $27 cart.

> Most of the codes that fail aren't fake. They're real codes aimed at somebody else.

## Where legitimate codes actually come from

If you want a code with a date and a set of terms behind it, there are four sources worth checking, in this order.

**Uber's own promotions and blog.** Uber publishes promo codes on its regional blog and in the app's Promotions tab. These are the codes Uber is contractually willing to stand behind, and they come with an expiry date attached.

**The restaurant or grocery brand's own site.** Launch partnerships produce the most generous codes on the platform. When Stop & Shop rolled out grocery delivery through Uber Eats across New York, New Jersey, Connecticut, Rhode Island and Massachusetts, the launch offer was 40% off a first order up to $25 with the code `Launch40` on a $40 minimum. That promotion expired on 31 May 2026, but the pattern repeats: a new merchant joins Uber Eats, and there's a fat first-order code for a few weeks.

**Student, military and verification platforms.** UNiDAYS and Student Beans have run multi-order offers, and coupons.com has tracked Veterans Day vouchers for military members. These are gated behind verification, which is precisely why they tend to survive longer than the codes on open coupon pages.

**Bank and card partnerships.** Card issuers buy delivery credits and statement credits as benefits. They're not promo codes, but they land in the same budget line.

Everything else — the aggregator pages with thirty "active codes" and a headline screaming 50% off — deserves scepticism. Those pages rank codes by usage count, not by verification, and a code that failed for 400 people still shows up as "last used 2 hours ago." Some of those sites also carry an affiliate incentive to list as many codes as possible, working or not.

## What to check before you paste a code in

Four things, and it takes about twenty seconds:

1. **Does it say "new customers only"?** If yes and you've ordered before, stop.
2. **Is the country right?** A UK code won't fire on a US account.
3. **Is there a minimum order value?** And does it exclude fees and taxes?
4. **Is there a stated expiry or usage cap?** No expiry usually means "we don't know."

One more thing worth knowing: promo codes don't stack. Two codes on one order is not a thing. Neither is a new-customer code on an existing account. If you're going to spend effort on this, spend it on the layer that stacks with everything.
